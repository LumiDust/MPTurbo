# 游戏内验收清单

本清单用于在真实 RimWorld 1.7 上验证 TurboTick。此前所有验证都在网络层与逻辑层，**游戏内行为尚未验收**。按顺序执行，任一步失败请把「设置页 → 诊断信息」整段发出来。

## 0. 环境

- [ ] RimWorld 1.7，Steam 版，已安装 Harmony。
- [ ] 两个独立实例（建议一台本机双开 + 一台另一台机器，或两台机器同局域网）。
- [ ] 两边 mod 列表完全一致：仅 Harmony + TurboTick，先排除第三方 mod 干扰。

## 1. 启动与补丁

- [ ] 游戏能进主菜单，`Player.log` 无 TurboTick 红字。
- [ ] 设置页诊断行 `补丁` 显示 `标记✓ 建造✓ 征召✓ 指令✓ 锁步✓ 应用✓`。任一为 `✗` 或 `缺失`，说明该入口没挂上，对应功能不会同步。

## 2. 连接

- [ ] 一端启动服务器：`dotnet TurboTick.Server.dll --host 0.0.0.0 --port 30572`。
- [ ] 两端填同一地址连接，诊断 `模式` 显示 `联机`，`房间` 不再是「计算兼容性指纹…」。
- [ ] 故意让一端多装一个 mod，确认被拒绝且提示是模组/版本不匹配。

## 3. 共享殖民地

- [ ] 控制者点「发布当前殖民地并开始共享」，另一端自动下载并载入**同一个殖民地**（看到相同的殖民者名字与布局）。
- [ ] 两端诊断 `epoch` 相同，`服务器tick` 持续增长，`本地tick` 跟随不超前。

## 4. 操作同步（核心）

依次验证，每项在 A 端操作，B 端应在 1 秒内出现相同结果：

- [ ] **标记**：A 划定挖掘区，B 看到相同格子被标记。
- [ ] **建造**：A 放置一面墙的蓝图，B 看到同一格、同材料、同朝向。
- [ ] **征召**：A 征召/解除一名殖民者，B 的该殖民者状态一致。
- [ ] **指令**：A 右键让殖民者去某格，B 看到同一目标点。
- [ ] **反向**：B 执行上述任一操作，A 同样收到。

## 5. 倍率

- [ ] HUD 中没有自建的 +/-、1x 或额外加速开关；设置页没有另一套倍率滑块。
- [ ] A 点击右下角原生常速/快速/超快按钮，B 的原生按钮高亮在服务器确认后同步。
- [ ] B 使用原有速度快捷键，A 跟随；单机原生键位及档位速度保持不变。
- [ ] 暂停图标与空格均全员暂停；暂停超过 5 秒后仍保持暂停，无服务端 tick 积累。
- [ ] 再次按空格恢复之前档位；晚加入者接收当前档位。
- [ ] 服务器加 `--controller-only` 后，访客点击原生按钮不会自行改速。
- [ ] 对话框/过场强制暂停和威胁强制常速仍由原版处理。
- [ ] 客户端/服务端配套使用协议 v2，旧端被握手拒绝。

## 6. 分叉与追赶

- [ ] 运行数分钟后，诊断无 `错误`，未出现「状态分叉」。
- [ ] B 中途退出再连接：能重新载入并追平，`本地tick` 追到服务器 tick 后正常操作。
- [ ] 控制者等待 3000 tick 触发检查点后，新加入的第三端能载入并只重放少量增量。

## 7. 已知不支持（不必报错）

- 交易、运输舱装载、组建远行队、囚犯/奴隶相关界面尚未纳入同步。
- 服务器无账号认证/TLS，勿在公网直接暴露。

## 记录

失败时请附：诊断信息全文、`Player.log` 中 `[TurboTick]` 行、服务器控制台最后 30 行、复现步骤。
